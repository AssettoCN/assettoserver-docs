# TimeDilationPlugin

该插件会根据太阳位置或一天中的时间动态调整时间倍率（time multiplier）。例如，可以用它让白天的时间流逝得更快、夜晚更慢。

::::note

需要在 `data_tracks_params.ini` 中提供赛道的经度和纬度。

::::

## 配置
在 `extra_cfg.yml` 中启用该插件
```yaml title="extra_cfg.yml"
EnablePlugins:
- TimeDilationPlugin
```
