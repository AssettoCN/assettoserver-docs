# RandomWeatherPlugin
该插件会随机切换天气。

::::note

要想获得平滑的天气过渡和降雨效果，你需要在 `extra_cfg.yml` 中将 `EnableWeatherFx` 设为 `true`。

::::

## 配置
在 `extra_cfg.yml` 中启用该插件
```yaml title="extra_cfg.yml"
EnablePlugins:
- RandomWeatherPlugin
```
