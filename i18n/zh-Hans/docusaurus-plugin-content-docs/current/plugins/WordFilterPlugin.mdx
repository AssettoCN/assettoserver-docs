# WordFilterPlugin
## 功能
* 禁止特定的玩家名
* 过滤聊天消息
* 在出现特定聊天消息时自动封禁
## 配置
在 `extra_cfg.yml` 中启用该插件
```yaml title="extra_cfg.yml"
EnablePlugins:
- WordFilterPlugin
```
