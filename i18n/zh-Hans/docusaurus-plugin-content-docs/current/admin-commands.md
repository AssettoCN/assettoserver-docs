## 获取管理员权限

`/admin <adminPassword>`

| 参数           | 描述                                |
| ------------- | ---------------------------------- |
| adminPassword | 在 `server_cfg.ini` 中设置的管理员密码 |

## 踢出玩家

`/kick <id> <reason>`  
`/kick_id <id> <reason>`

| 参数    | 描述                                 |
| ------ | ---------------------------------- |
| id     | 要踢出的玩家的车辆 ID 或名称。           |
| reason | 可选，将显示该玩家被踢出的原因。         |

## 封禁玩家

`/ban <id> <reason>`  
`/ban_id <id> <reason>`

| 参数    | 描述                                 |
| ------ | ---------------------------------- |
| id     | 要封禁的玩家的车辆 ID 或名称            |
| reason | 可选，将显示该玩家被封禁的原因。         |

## 强制进入下一个会话

`/next_session`

| 参数 | 描述                 |
| --- | ------------------- |
| 无  | 强制服务器进入下一个会话。 |

## 重启会话

`/restart_session`

| 参数 | 描述         |
| --- | ----------- |
| 无  | 重启当前会话。  |

## 设置服务器时间

`/settime <time>`

| 参数  | 描述                                          |
| ---- | -------------------------------------------- |
| time | 24 小时制的时间，例如 `/settime 13:45`           |

## 设置天气配置

`/setweather <weatherId>`

| 参数       | 描述                                                                     |
| --------- | ----------------------------------------------------------------------- |
| weatherId | `server_cfg.ini` 中指定的天气 ID <br/> 例如，如果想使用 `WEATHER_0`，则输入 `/setweather 0` |

## 列出可用的 CSP WeatherFX 类型

`/cspweather`

| 参数 | 描述                        |
| --- | -------------------------- |
| 无  | 列出所有可用的 CSP WeatherFX 类型。 |

## 设置 CSP 天气

`/setcspweather <weatherType> <transitionDuration>`

| 参数               | 描述                                                                                       |
| ----------------- | ----------------------------------------------------------------------------------------- |
| weatherType        | WeatherFX 类型名称，见[可选值列表](./misc/wfx-types.md)，或在游戏内使用 `/cspweather` 查看。     |
| transitionDuration | 天气过渡时长（秒），需要在 `extra_cfg.yml` 中将 `EnableWeatherFx` 设为 `true`                  |

## 设置降雨属性

`/setrain <intensity> <wetness> <water>`

| 参数       | 范围    | 描述                |
| --------- | ------ | ------------------ |
| intensity | `0 - 1` | 降雨强度。           |
| wetness   | `0 - 1` | 赛道湿度。           |
| water     | `0 - 1` | 赛道上的积水程度。     |

## 设置赛道抓地力

`/setgrip <gripValue>`

| 参数       | 范围    | 描述             |
| --------- | ------ | --------------- |
| gripValue | `0 - 1` | 赛道抓地力数值。   |

## 计算与玩家的距离

`/distance <id>`

| 参数 | 描述                                |
| --- | ---------------------------------- |
| id  | 要计算与其距离的玩家的车辆 ID 或名称。   |

## 强制玩家开启车头灯

`/forcelights <on/off> <id>`

| 参数    | 描述                                |
| ------ | ---------------------------------- |
| on/off | On = 强制开启车头灯，Off = 取消强制车头灯  |
| id     | 玩家的车辆 ID 或名称。                  |

:::note

对玩家强制开启车头灯后，该玩家仍可以在本地自行开关车灯。不过在所有其他玩家看来，他的车灯是打开的。

:::

## 设置限流器

`/restrict <id> <value>`

| 参数   | 范围      | 描述                                                                            |
| ----- | -------- | ------------------------------------------------------------------------------ |
| id    |          | 玩家的车辆 ID 或名称。                                                            |
| value | `0 - 400` | 限制功率区间顶端的动力输出，不会完全抹杀总功率。 <br/> 计算公式：`HP_Final = HP_Original * (1 - rpm * (restrictor / 4000000))` |

## 设置配重

`/ballast <id> <ballast>`

| 参数     | 描述                                |
| ------- | ---------------------------------- |
| id      | 玩家的车辆 ID 或名称。                |
| ballast | 要为车辆添加的配重（单位 kg）。过量的配重会严重影响操控和车辆行为。 |

## 设置服务器配置参数

:::caution

仅用于测试！通过此命令做出的所有更改在服务器重启后都会丢失。

:::

`/set <key> <value>`

| 参数   | 描述                     |
| ----- | ----------------------- |
| key   | 要设置的服务器配置参数名称。   |
| value | 要为该参数设置的值。          |

:::note

`server_cfg.ini` 中的参数带有 `Server.` 前缀，`extra_cfg.yml` 中的参数带有 `Extra.` 前缀。  
并非所有值都可以在运行时修改。

**示例：**  
`/set Server.Name Start 123` - 将服务器名称改为 `Start 123`  
`/set Extra.AiParams.MinAiSafetyDistanceMeters 100` - 将 AI 车辆之间的最小间距设为 `100` 米  
`/set Extra.AiParams.SplineHeightOffsetMeters 0.2` - 将行驶线路高度偏移设为 `0.2` 米

:::

| ------- | -------------------------------------------------------------- |

## 开启 noclip

`/noclip <boolean>`

| 参数     | 描述                    |
| ------- | ---------------------- |
| boolean | `true` 启用，`false` 禁用。 |

:::note

此命令只会禁用车辆之间的碰撞，**不能**让你穿过赛道几何体。  
需要在 extra_cfg.yml 中将最低 CSP 版本要求设为 0.2.8 (3424) 或更高。

:::
