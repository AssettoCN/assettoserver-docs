# PatreonHubPlugin
将该服务器连接到一个 AssettoServer Hub 实例。其他插件的排行榜需要此插件才能工作。

## 配置
在 `extra_cfg.yml` 中启用该插件
```yaml title="extra_cfg.yml"
EnablePlugins:
  - PatreonHubPlugin
```
